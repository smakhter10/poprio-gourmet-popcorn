# POPRIO — Gourmet Popcorn

The official comic-book-inspired website for **POPRIO** (`eatpoprio.com`), a premium gourmet popcorn brand crafted in Bangladesh.

## Features

- **Comic-Book Visual Identity**: Hand-crafted comic borders, bold typography, hard shadows, dynamic stickers, and vibrant palettes.
- **Interactive Fan Showcase**: Interactive 5-pack hero fan presentation with physics-inspired GSAP animations.
- **Scroll-Driven Storytelling**: Sticky scroll-driven animated "Origin of the Pop" narrative section.
- **Responsive Sticky Promotional Video**: Seamless scroll-shrink trailer showcase.
- **Interactive Flavourverse Bento**: Connected product display with interactive modal cards and WhatsApp order generator.
- **Interactive Touch & Cursor Effects**: Optimized responsive canvas and grid ripple effects (`GlyphSwell` and `InteractiveGrid`).
- **Full Accessibility**: Complete `prefers-reduced-motion` compliance, accessible ARIA attributes, and semantic HTML5.

## Tech Stack

- **Framework**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: GSAP & ScrollTrigger
- **Icons**: Lucide React
- **Bundler**: Vite

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or newer)
- npm (or yarn / pnpm)

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
